# Insta Posts

Instagram posts clone built with Node.js, Express, EJS

## Features
- Create, Read, Update, Delete posts
- Like button
- Image URL support
- UUID for unique post IDs

## Tech Stack
- Node.js
- Express.js
- EJS (Template Engine)
- method-override
- UUID

## How to run
npm install ; 
npm run dev
